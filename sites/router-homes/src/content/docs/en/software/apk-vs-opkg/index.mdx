## One line

- **25.12+**: `apk`, packages are `.apk`;
- **24.10 and older**: `opkg`, packages are `.ipk`;
- They are not related by renaming; **do not rename `.ipk` to `.apk`**;
- After upgrading to 25.12, reinstall plugins from `apk` feeds; config can be backed up/restored.

## Check which side you are on

```sh
cat /etc/openwrt_release
command -v apk
command -v opkg
```

This lab: 25.12.6, `apk` exists, `opkg` does not.

## Comparison

| Item | 25.12 `apk` | 24.10 `opkg` |
|---|---|---|
| Format | `.apk` | `.ipk` |
| Feed file | `/etc/apk/repositories.d/distfeeds.list` | `/etc/opkg/distfeeds.conf` |
| Update index | `apk update` | `opkg update` |
| Install | `apk add <pkg>` | `opkg install <pkg>` |
| Remove | `apk del <pkg>` | `opkg remove <pkg>` |
| Search | `apk search <term>` | `opkg list \| grep <term>` |
| Installed | `apk list --installed` | `opkg list-installed` |
| Package info | `apk info -a <pkg>` | `opkg info <pkg>` |
| Clean cache | `apk cache clean` | `opkg clean` |

## Feeds and architecture

25.12:

```text
https://downloads.openwrt.org/releases/25.12.6/targets/x86/64/packages/packages.adb
https://downloads.openwrt.org/releases/25.12.6/packages/x86_64/base/packages.adb
https://downloads.openwrt.org/releases/25.12.6/targets/x86/64/kmods/<kernel-hash>/packages.adb
```

24.10:

```text
src/gz openwrt_core https://downloads.openwrt.org/releases/24.10.8/targets/x86/64/packages
src/gz openwrt_base https://downloads.openwrt.org/releases/24.10.8/packages/x86_64/base
```

- `release`, `target`, `arch` and kmod hash must match;
- Mixing official/ImmortalWrt/iStoreOS feeds can break ABI/signatures/names;
- A China mirror changes the host/path prefix only; do not change target/arch.

## When upgrading to 25.12

1. Back up `/etc/config` and the package list (see 018);
2. Record 24.10 `opkg list-installed`;
3. Upgrade/reflash 25.12 (see 019);
4. Reinstall plugins from `apk` feeds;
5. Restore config, verify LuCI/service/DNS;
6. Do not convert `.ipk` to `.apk` or copy old package directories.

This lab's 25.12 sysupgrade kept config but dropped packages 239→182; SQM/OpenClash needed reinstall.

## Common failures

### `apk: not found`

- Firmware is 24.10 or older; use `opkg`;
- “Installing an apk package manager” is not the fix; check the release first.

### `opkg: not found`

- Firmware is 25.12+; use `apk`;
- Old tutorials/scripts using `opkg` do not apply directly.

### `.ipk` will not install

- 25.12 uses `.apk`;
- Renaming does not change the format;
- Find the `.apk` for the release/target/arch or rebuild.

### 404/signature/dependency errors

- release/target/arch/kmod hash mismatch;
- mixed feeds;
- system time/certificates;
- do not routinely bypass with `--allow-untrusted`.

### No LuCI menu after upgrade

- main program installed without `luci-app-*`;
- old plugin not reinstalled;
- browser cache/relogin;
- see 017.
