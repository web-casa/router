## Outcome

The OpenWrt VM routes traffic, the Proxmox host remains reachable, and you can still get to a backup when the router VM is stopped.

## Steps

<Step where="router-shell" title="Confirm interfaces" expected="wan has an address; lan is the LAN gateway.">

```sh
ip -br addr
```

</Step>

<Step where="client" title="Verify host and guest access" expected="The client reaches the OpenWrt gateway and the Proxmox UI.">

Test both the LAN gateway and the Proxmox host address from a client.

</Step>

<Step where="luci" title="Record the recovery path" expected="You know how to reach the host and restore the VM if routing fails.">

Write down the physical port, bridge, VM NIC and management address before changing the WAN configuration.

</Step>

## Recovery

If the router VM loses connectivity, use the Proxmox host console. Do not rely on a backup that is only reachable through the router VM.
