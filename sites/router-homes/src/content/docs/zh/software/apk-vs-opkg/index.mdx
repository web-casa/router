## 一句话

- **25.12+**：`apk`，包是 `.apk`；
- **24.10 及更早**：`opkg`，包是 `.ipk`；
- 两者不是改后缀的关系，**不能把 `.ipk` 改名成 `.apk` 安装**；
- 升级到 25.12 后，插件要按 `apk` 源重装，配置可备份/恢复。

## 先确认你在哪一边

```sh
cat /etc/openwrt_release
command -v apk
command -v opkg
```

本实验：25.12.6，`apk` 存在，`opkg` 不存在。

## 对照表

| 项目 | 25.12 `apk` | 24.10 `opkg` |
|---|---|---|
| 包格式 | `.apk` | `.ipk` |
| 源文件 | `/etc/apk/repositories.d/distfeeds.list` | `/etc/opkg/distfeeds.conf` |
| 更新索引 | `apk update` | `opkg update` |
| 安装 | `apk add <pkg>` | `opkg install <pkg>` |
| 删除 | `apk del <pkg>` | `opkg remove <pkg>` |
| 搜索 | `apk search <term>` | `opkg list \| grep <term>` |
| 已安装 | `apk list --installed` | `opkg list-installed` |
| 包信息 | `apk info -a <pkg>` | `opkg info <pkg>` |
| 清理缓存 | `apk cache clean` | `opkg clean` |

## 源和架构

25.12：

```text
https://downloads.openwrt.org/releases/25.12.6/targets/x86/64/packages/packages.adb
https://downloads.openwrt.org/releases/25.12.6/packages/x86_64/base/packages.adb
https://downloads.openwrt.org/releases/25.12.6/targets/x86/64/kmods/<kernel-hash>/packages.adb
```

24.10：

```text
src/gz openwrt_core https://downloads.openwrt.org/releases/24.10.8/targets/x86/64/packages
src/gz openwrt_base https://downloads.openwrt.org/releases/24.10.8/packages/x86_64/base
```

- `release`、`target`、`arch`、kmod 内核 hash 必须匹配；
- 混用官方/ImmortalWrt/iStoreOS 的源，ABI/签名/包名都可能不匹配；
- 国内镜像只替换主机名/路径前缀，不要改 target/arch。

## 升级到 25.12 时

1. 备份 `/etc/config` 和包列表（见 018）；
2. 记录 24.10 的 `opkg list-installed`；
3. 升级/重刷 25.12（见 019）；
4. 用 `apk` 源重装插件；
5. 恢复配置，验证 LuCI/服务/DNS；
6. 不要尝试把 `.ipk` 转成 `.apk`，也不要直接复制旧包目录。

本实验的 25.12 sysupgrade：配置保留，但包从 239 降到 182；SQM/OpenClash 需要重装。

## 常见失败

### `apk: not found`

- 固件是 24.10 或更早，应该用 `opkg`；
- 不是“装一个 apk 包管理器”能解决；先看固件版本。

### `opkg: not found`

- 固件是 25.12+，应该用 `apk`；
- 旧教程/脚本里的 `opkg` 不能直接套用。

### `.ipk` 装不上

- 25.12 使用 `.apk`；
- 改后缀不会改变包格式；
- 找对应 release/target/arch 的 `.apk`，或重新编译。

### 404/签名/依赖错误

- release/target/arch/kmod hash 不匹配；
- 混源；
- 系统时间/证书；
- 不要长期用 `--allow-untrusted` 绕过。

### 升级后 LuCI 没菜单

- 只装了主程序，没装 `luci-app-*`；
- 旧插件未重装；
- 浏览器缓存/需要重登；
- 见 017。
