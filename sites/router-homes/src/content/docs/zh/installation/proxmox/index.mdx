## 完成后你能确认什么

OpenWrt 虚拟机能转发流量，Proxmox 宿主机仍可访问，路由 VM 关闭时你仍能拿到备份。

## 操作步骤

<Step where="router-shell" title="确认接口" expected="wan 有地址，lan 是 LAN 网关。">

```sh
ip -br addr
```

</Step>

<Step where="client" title="验证宿主机与虚拟机都能访问" expected="终端能到 OpenWrt 网关和 Proxmox 管理页。">

从一台终端分别访问 LAN 网关和 Proxmox 宿主机地址。

</Step>

<Step where="luci" title="记录恢复路径" expected="你知道怎么进宿主机、怎么恢复 VM。">

改 WAN 前，把物理口、bridge、VM 网卡和管理地址写下来。

</Step>

## 恢复

路由 VM 失联时用 Proxmox 宿主机控制台。不要把备份只放在必须经过路由 VM 才能访问的位置。
