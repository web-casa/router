## ひとことで言うと

フェイルセーフモードは、既知の最小構成でOpenWrtを `192.168.1.1` に起動し、壊れた設定を修復できるようにします。sysupgradeはファームウェアを置き換え、指定しない限り設定を保持します。

## フェイルセーフモード

- **入り方:** 起動中に2〜4秒の入力受付があります。そのタイミングでデバイスのほぼ任意のボタンを押すか、シリアルコンソールで `f` を入力してEnterを押します。
- **得られる状態:** ルーターは `192.168.1.1/24` で起動し、DHCPと無線はオフ、必須のサービスだけが動きます。コンピューターにそのサブネットの静的アドレスを設定して、SSHで接続します。
- **できること:** `mount_root` でオーバーレイをマウントしてファイルを修復するか、`firstboot && reboot` ですべての設定をリセットします。
- フェイルセーフにはSquashFSイメージが必要です。

## sysupgrade

- 既定では設定を保持します。`-n` を付けると設定を保持せずに書き込みます。
- `sysupgrade -b <file>` は、`sysupgrade.conf` に記載されたファイルの `.tar.gz` バックアップを作成します。`-r <file>` で復元し、`-l` で保存対象を一覧表示します。

## ルーターで確認する

このコマンドは読み取りのみです。

```sh
sysupgrade -l | head
```

## 注意

- ファクトリーリセットはすべての設定を消去します。先にバックアップを取ってください。
- フェイルセーフではDHCPが動きません。コンピューターに静的IPを設定しないと、ルーターが壊れたように見えます。
