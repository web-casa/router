## 一言でいうと

DSA(Distributed Switch Architecture)は、ネットワークスイッチ向けの Linux カーネルのサブシステムです。DSA 対応デバイスでは、前面の各ポートが `lan1`〜`lan4` のように独立したインターフェースとして現れ、それらが `br-lan` にブリッジされます。

## 経緯

- DSA は 21.02 で初めて登場し、一部のターゲットで従来の swconfig を置き換えました。
- 22.03 では、bcm53xx や lantiq xrx200 のすべてなど、さらに多くのターゲットが DSA に移行しました。
- sysupgrade では、swconfig の設定を DSA に移行できません。お使いのデバイスが DSA に切り替わった場合は、ネットワークを設定し直してください。

## DSA での VLAN

VLAN は `/etc/config/network` 内の `config bridge-vlan` セクションで設定します。インターフェースは `br-lan.1` のように、VLAN のサフィックスを付けてブリッジ上に置かれます。各ポートは VLAN ごとに tagged か untagged かを指定します。

## ルーターで確認する

```sh
ip -br link
uci show network | grep -E 'bridge-vlan|=device'
```

代わりに `config switch` と `switch_vlan` セクションが表示される場合、そのデバイスはまだ swconfig を使っており、DSA のガイドは当てはまりません。
