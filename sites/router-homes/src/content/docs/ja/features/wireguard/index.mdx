## 一言で言うと

WireGuardは、2020-03-29にリリースされたLinux 5.6からメインラインに含まれています。OpenWrtでは `wireguard` というネットワークプロトコルとして提供され、他のインターフェースと同じように設定します。

## 構成要素

- `kmod-wireguard`: カーネルモジュール。
- `wireguard-tools`: `wg` コマンド。カーネルモジュールに依存し、`wireguard` プロトコルをnetifdに登録します。
- `luci-proto-wireguard`: LuCIでインターフェースを作成するときに、プロトコルとして「WireGuard VPN」を追加します。

## 家庭での用途

- **サーバー:** 外出先から自宅のネットワークにアクセスする。
- **クライアント:** ルーターのトラフィックの全部または一部を、リモートのピア経由で送る。

どちらの場合も、トンネルは `/etc/config/network` のインターフェースです。ファイアウォールゾーンが必要で、サーバーの場合はWANでUDPポートを開ける必要もあります。

## ルーターで確認する

```sh
wg show
uci show network | grep wireguard
```
