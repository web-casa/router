## 一言で言うと

25.12以降、OpenWrtはapk（Alpine Package Keeper、バージョン3）でソフトウェアをインストール・削除します。24.10以前は引き続きopkgを使います。

## 変更された理由

25.12.0の告知によると、OpenWrtのopkgフォークはメンテナンスされなくなりました。パッケージ名の変更は少ないものの、コマンドはすべて変わっています。

## コマンド対応表

| 作業 | apk (25.12) | opkg (24.10) |
|---|---|---|
| パッケージインデックスの更新 | `apk update` | `opkg update` |
| インストール | `apk add <pkg>` | `opkg install <pkg>` |
| 削除 | `apk del <pkg>` | `opkg remove <pkg>` |
| インストール済み一覧 | `apk list --installed` | `opkg list-installed` |
| 更新可能な一覧 | `apk list --upgradeable` | `opkg list-upgradable` |
| ファイルを所有するパッケージ | `apk info --who-owns <file>` | `opkg search <file>` |

## ほかの違い

- パッケージファイルの拡張子は `.apk`、パッケージインデックスは `packages.adb` です。
- リポジトリは `/etc/apk/repositories.d/` 以下に記載されます。
- 自分でビルドしたパッケージは署名がないため、インストールには `--allow-untrusted` が必要です。

## 注意点

- **システムのアップグレードに `apk upgrade` を使わないでください。** OpenWrt wikiでも警告されています。ファームウェアはattended sysupgradeクライアントでアップグレードします。25.12ではLuCIアプリが標準でインストールされています。
- 25.12にopkgのコマンドを、24.10にapkのコマンドを貼り付けないでください。先にどちらを使っているか確認します。

## ルーターで確認する

```sh
apk list --installed | head
ls /etc/apk/repositories.d/
```
