これはRouter.HomesのPhase 0の縦断スライスです。コンテンツ全体を執筆する前に、多言語ルーティング、環境カード、実行場所つきの手順、ルートのリダイレクトを検証します。

## ページの読み方

1. まず環境カードを確認します。
2. 記載されたファームウェアとデバイスのリビジョンでのみ手順に従います。
3. ルーターとクライアントの両方で期待される結果を確認します。
4. 復旧手段を常に確保しておきます。
