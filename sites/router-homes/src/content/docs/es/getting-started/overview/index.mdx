Este es el corte vertical de la Fase 0 de Router.Homes. Valida el enrutamiento bilingüe, la tarjeta de entorno, los pasos con ubicación de ejecución y la redirección raíz antes de redactar el conjunto completo de contenido.

## Cómo leer una página

1. Revisa primero la tarjeta de entorno.
2. Sigue los pasos solo con el firmware y la revisión de dispositivo indicados.
3. Confirma el resultado esperado en el enrutador y en un cliente.
4. Mantén abierta la vía de recuperación.
