## En una frase

DSA (Distributed Switch Architecture) es el subsistema del kernel de Linux para switches de red. En los dispositivos DSA cada puerto frontal aparece como su propia interfaz, como `lan1`–`lan4`, y esos puertos se unen en el puente `br-lan`.

## Origen

- DSA apareció por primera vez en la 21.02 y reemplazó al antiguo swconfig en algunos targets.
- La 22.03 convirtió más targets, por ejemplo todo bcm53xx y lantiq xrx200.
- Sysupgrade no puede migrar una configuración swconfig a DSA. Si tu dispositivo cambió de sistema, configura la red de nuevo.

## VLAN en DSA

Las VLAN son secciones `config bridge-vlan` en `/etc/config/network`. Las interfaces se asientan después sobre el puente con un sufijo de VLAN, como en `br-lan.1`. Cada puerto va con etiqueta (tagged) o sin ella (untagged) en cada VLAN.

## Compruébalo en tu router

```sh
ip -br link
uci show network | grep -E 'bridge-vlan|=device'
```

Si ves secciones `config switch` y `switch_vlan`, el dispositivo todavía usa swconfig y las guías de DSA no se aplican.
