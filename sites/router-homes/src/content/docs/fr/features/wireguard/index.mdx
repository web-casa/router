## En une phrase

WireGuard fait partie du noyau Linux principal depuis la 5.6, publiée le 2020-03-29. Sur OpenWrt, c'est un protocole réseau nommé `wireguard`, que vous configurez comme n'importe quelle autre interface.

## Les éléments

- `kmod-wireguard` : le module noyau.
- `wireguard-tools` : la commande `wg`. Il dépend du module noyau et enregistre le protocole `wireguard` auprès de netifd.
- `luci-proto-wireguard` : ajoute « WireGuard VPN » comme protocole lorsque vous créez une interface dans LuCI.

## À quoi cela sert à la maison

- **Serveur :** accéder à votre réseau domestique depuis l'extérieur.
- **Client :** envoyer tout le trafic du routeur, ou une partie, par un pair distant.

Dans les deux cas, le tunnel est une interface dans `/etc/config/network`. Il a besoin d'une zone de pare-feu et, sur un serveur, d'un port UDP ouvert sur le WAN.

## Le voir sur votre routeur

```sh
wg show
uci show network | grep wireguard
```
