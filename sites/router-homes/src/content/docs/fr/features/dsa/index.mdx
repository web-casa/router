## En une phrase

DSA (Distributed Switch Architecture) est le sous-système du noyau Linux dédié aux commutateurs réseau. Sur les appareils DSA, chaque port avant apparaît comme sa propre interface, telle que `lan1`–`lan4`, et ces ports sont reliés dans `br-lan`.

## D'où cela vient

- DSA est apparu dans la version 21.02, en remplacement de l'ancien swconfig sur certaines cibles.
- La version 22.03 en a converti davantage, par exemple tout bcm53xx et lantiq xrx200.
- Sysupgrade ne peut pas migrer une configuration swconfig vers DSA. Si votre appareil est passé à DSA, reconfigurez le réseau.

## VLAN avec DSA

Les VLAN sont des sections `config bridge-vlan` dans `/etc/config/network`. Les interfaces se placent ensuite sur le pont avec un suffixe de VLAN, comme `br-lan.1`. Chaque port est étiqueté ou non étiqueté pour chaque VLAN.

## Voir cela sur votre routeur

```sh
ip -br link
uci show network | grep -E 'bridge-vlan|=device'
```

Si vous voyez à la place des sections `config switch` et `switch_vlan`, l'appareil utilise encore swconfig, et les guides DSA ne s'appliquent pas.
