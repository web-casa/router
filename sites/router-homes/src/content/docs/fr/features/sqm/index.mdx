## En une phrase

SQM (Smart Queue Management) met en forme le trafic légèrement en dessous du débit de votre ligne, de sorte que la file se forme dans le routeur, où elle peut être gérée, plutôt que dans le modem. Utilisé avec la discipline de file CAKE, il maintient une faible latence quand la ligne est occupée. Ce problème s'appelle le bufferbloat.

## Ce que recommande le guide OpenWrt

1. Installez `luci-app-sqm`, ou `sqm-scripts` si vous n'utilisez pas LuCI.
2. Mesurez votre débit réel en téléchargement et en envoi, puis réglez les deux à **90 %** de la valeur mesurée.
3. Choisissez `cake` avec `piece_of_cake.qos`.
4. Testez de nouveau sous charge et ajustez. `fq_codel` avec `simple.qos` est l'alternative plus légère mais moins complète.

CAKE fait partie du noyau Linux depuis la version 4.19.

## Voir cela sur votre routeur

Après l'installation de SQM :

```sh
cat /etc/config/sqm
```

## Attention

- La mise en forme consomme du CPU. Sur une ligne rapide, un petit routeur peut ne pas suivre, comparez donc le débit et la latence avant et après.
- Réglez les débits à partir d'une mesure, pas à partir du débit annoncé de votre abonnement.
