## En une ligne

- **25.12+** : `apk`, les paquets sont des `.apk` ;
- **24.10 et antérieures** : `opkg`, les paquets sont des `.ipk` ;
- Ils ne sont pas liés par un simple renommage ; **ne renommez pas un `.ipk` en `.apk`** ;
- Après la mise à niveau vers 25.12, réinstallez les extensions depuis les dépôts `apk` ; la configuration peut être sauvegardée/restaurée.

## Vérifier de quel côté vous êtes

```sh
cat /etc/openwrt_release
command -v apk
command -v opkg
```

Ce laboratoire : 25.12.6, `apk` existe, `opkg` n'existe pas.

## Comparaison

| Élément | `apk` de 25.12 | `opkg` de 24.10 |
|---|---|---|
| Format | `.apk` | `.ipk` |
| Fichier de dépôts | `/etc/apk/repositories.d/distfeeds.list` | `/etc/opkg/distfeeds.conf` |
| Mettre à jour l'index | `apk update` | `opkg update` |
| Installer | `apk add <pkg>` | `opkg install <pkg>` |
| Supprimer | `apk del <pkg>` | `opkg remove <pkg>` |
| Rechercher | `apk search <term>` | `opkg list \| grep <term>` |
| Installés | `apk list --installed` | `opkg list-installed` |
| Infos sur un paquet | `apk info -a <pkg>` | `opkg info <pkg>` |
| Vider le cache | `apk cache clean` | `opkg clean` |

## Dépôts et architecture

25.12 :

```text
https://downloads.openwrt.org/releases/25.12.6/targets/x86/64/packages/packages.adb
https://downloads.openwrt.org/releases/25.12.6/packages/x86_64/base/packages.adb
https://downloads.openwrt.org/releases/25.12.6/targets/x86/64/kmods/<kernel-hash>/packages.adb
```

24.10 :

```text
src/gz openwrt_core https://downloads.openwrt.org/releases/24.10.8/targets/x86/64/packages
src/gz openwrt_base https://downloads.openwrt.org/releases/24.10.8/packages/x86_64/base
```

- La version (`release`), la cible (`target`), l'architecture (`arch`) et le hash des kmods doivent correspondre ;
- Mélanger les dépôts officiels/ImmortalWrt/iStoreOS peut casser l'ABI, les signatures ou les noms ;
- Un miroir chinois ne change que le préfixe d'hôte/de chemin ; ne changez ni la cible ni l'architecture.

## Opérations courantes

<Step where="router-shell" title="Installer un paquet sous 25.12" expected="La mise à jour, la recherche, l'installation et la vérification utilisent toutes apk.">

```sh
apk search -x sqm-scripts
apk add sqm-scripts
apk info -e sqm-scripts
apk list --installed | wc -l
```

Ce laboratoire : officiel et TUNA avaient tous deux 11220 paquets ; `sqm-scripts 1.7.2-r1` installé.

```sh
opkg list | grep sqm-scripts
opkg install sqm-scripts
opkg list-installed | grep sqm-scripts
```

Ce sont les commandes équivalentes officielles, **non exécutées ici** (pas d'appareil 24.10) ; ne les présentez pas comme une sortie mesurée.

## Lors de la mise à niveau vers 25.12

1. Sauvegardez `/etc/config` et la liste des paquets (voir 018) ;
2. Notez `opkg list-installed` de 24.10 ;
3. Mettez à niveau/reflashez 25.12 (voir 019) ;
4. Réinstallez les extensions depuis les dépôts `apk` ;
5. Restaurez la configuration, vérifiez LuCI, les services et le DNS ;
6. Ne convertissez pas les `.ipk` en `.apk` et ne copiez pas d'anciens répertoires de paquets.

Dans ce laboratoire, le sysupgrade de 25.12 a conservé la configuration mais fait passer les paquets de 239 à 182 ; SQM/OpenClash ont dû être réinstallés.

## Échecs courants

### `apk: not found`

- Le firmware est en 24.10 ou plus ancien ; utilisez `opkg` ;
- « Installer un gestionnaire de paquets apk » n'est pas la solution ; vérifiez d'abord la version.

### `opkg: not found`

- Le firmware est en 25.12+ ; utilisez `apk` ;
- Les anciens tutoriels/scripts qui utilisent `opkg` ne s'appliquent pas directement.

### Le `.ipk` ne s'installe pas

- 25.12 utilise des `.apk` ;
- Renommer ne change pas le format ;
- Trouvez le `.apk` correspondant à la version/cible/architecture, ou recompilez.

### Erreurs 404/signature/dépendances

- incompatibilité version/cible/architecture/hash des kmods ;
- dépôts mélangés ;
- heure système/certificats ;
- ne contournez pas systématiquement avec `--allow-untrusted`.

### Aucun menu LuCI après la mise à niveau

- le programme principal est installé sans `luci-app-*` ;
- l'ancienne extension n'a pas été réinstallée ;
- cache du navigateur/reconnexion ;
- voir 017.
