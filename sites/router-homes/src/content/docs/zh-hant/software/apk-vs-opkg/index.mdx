## 一句話

- **25.12 以上**：`apk`，套件為 `.apk`；
- **24.10 及更早**：`opkg`，套件為 `.ipk`；
- 兩者無法靠改名轉換；**不要把 `.ipk` 改名為 `.apk`**；
- 升級到 25.12 後，請從 `apk` 套件來源重新安裝外掛；設定可以備份/還原。

## 檢查你屬於哪一邊

```sh
cat /etc/openwrt_release
command -v apk
command -v opkg
```

本實驗：25.12.6，有 `apk`，沒有 `opkg`。

## 比較

| 項目 | 25.12 `apk` | 24.10 `opkg` |
|---|---|---|
| 格式 | `.apk` | `.ipk` |
| 套件來源檔 | `/etc/apk/repositories.d/distfeeds.list` | `/etc/opkg/distfeeds.conf` |
| 更新索引 | `apk update` | `opkg update` |
| 安裝 | `apk add <pkg>` | `opkg install <pkg>` |
| 移除 | `apk del <pkg>` | `opkg remove <pkg>` |
| 搜尋 | `apk search <term>` | `opkg list \| grep <term>` |
| 已安裝 | `apk list --installed` | `opkg list-installed` |
| 套件資訊 | `apk info -a <pkg>` | `opkg info <pkg>` |
| 清除快取 | `apk cache clean` | `opkg clean` |

## 套件來源與架構

25.12：

```text
https://downloads.openwrt.org/releases/25.12.6/targets/x86/64/packages/packages.adb
https://downloads.openwrt.org/releases/25.12.6/packages/x86_64/base/packages.adb
https://downloads.openwrt.org/releases/25.12.6/targets/x86/64/kmods/<kernel-hash>/packages.adb
```

24.10：

```text
src/gz openwrt_core https://downloads.openwrt.org/releases/24.10.8/targets/x86/64/packages
src/gz openwrt_base https://downloads.openwrt.org/releases/24.10.8/packages/x86_64/base
```

- `release`、`target`、`arch` 與 kmod 雜湊值必須相符；
- 混用官方/ImmortalWrt/iStoreOS 套件來源可能破壞 ABI/簽章/名稱；
- 中國鏡像站只改變主機/路徑前綴；不要更動 target/arch。

## 升級到 25.12 時

1. 備份 `/etc/config` 與套件清單（見 018）；
2. 記錄 24.10 的 `opkg list-installed`；
3. 升級/重新刷入 25.12（見 019）；
4. 從 `apk` 套件來源重新安裝外掛；
5. 還原設定，驗證 LuCI/服務/DNS；
6. 不要把 `.ipk` 轉換成 `.apk`，也不要複製舊的套件目錄。

本實驗的 25.12 sysupgrade 保留了設定，但套件從 239 個減少為 182 個；SQM/OpenClash 需要重新安裝。

## 常見失敗

### `apk: not found`

- 韌體是 24.10 或更舊；請使用 `opkg`；
- 「安裝 apk 套件管理員」不是解法；請先檢查版本。

### `opkg: not found`

- 韌體是 25.12 以上；請使用 `apk`；
- 使用 `opkg` 的舊教學/腳本不能直接套用。

### `.ipk` 無法安裝

- 25.12 使用 `.apk`；
- 改名不會改變格式；
- 請找出對應版本/target/架構的 `.apk`，或自行重新建置。

### 404/簽章/相依性錯誤

- 版本/target/架構/kmod 雜湊值不符；
- 混用套件來源；
- 系統時間/憑證；
- 不要習慣性地用 `--allow-untrusted` 繞過。

### 升級後沒有 LuCI 選單

- 安裝了主程式，但沒有 `luci-app-*`；
- 舊外掛沒有重新安裝；
- 瀏覽器快取/重新登入；
- 見 017。
