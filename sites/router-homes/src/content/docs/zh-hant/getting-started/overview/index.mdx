這是 Router.Homes 的 Phase 0 垂直切片。在撰寫完整內容之前，它用來驗證雙語路由、環境卡片、執行位置步驟，以及根目錄重新導向。

## 如何閱讀頁面

1. 先檢查環境卡片。
2. 只在所述的韌體與裝置版本下遵循這些步驟。
3. 在路由器與用戶端上確認預期結果。
4. 保持復原路徑暢通。
