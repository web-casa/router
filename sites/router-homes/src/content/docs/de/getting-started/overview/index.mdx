Dies ist der vertikale Phase-0-Ausschnitt für Router.Homes. Er validiert das zweisprachige Routing, die Umgebungskarte, die Schritte mit Ausführungsort und die Root-Weiterleitung, bevor der vollständige Inhalt geschrieben wird.

## So lesen Sie eine Seite

1. Prüfen Sie zuerst die Umgebungskarte.
2. Folgen Sie den Schritten nur bei der angegebenen Firmware und Geräterevision.
3. Bestätigen Sie das erwartete Ergebnis auf dem Router und auf einem Client.
4. Halten Sie den Wiederherstellungsweg offen.
