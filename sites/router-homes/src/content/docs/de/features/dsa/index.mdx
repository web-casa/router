## In einem Satz

DSA (Distributed Switch Architecture) ist das Linux-Kernel-Subsystem für Netzwerk-Switches. Auf DSA-Geräten erscheint jeder Frontport als eigene Schnittstelle, etwa `lan1`–`lan4`, und diese Ports sind in `br-lan` gebridged.

## Herkunft

- DSA tauchte erstmals in 21.02 auf und ersetzte auf einigen Targets das ältere swconfig.
- 22.03 stellte weitere Targets um, zum Beispiel alle von bcm53xx und lantiq xrx200.
- Sysupgrade kann eine swconfig-Konfiguration nicht auf DSA migrieren. Wenn Ihr Gerät umgestellt wurde, richten Sie das Netzwerk neu ein.

## VLANs unter DSA

VLANs sind `config bridge-vlan`-Abschnitte in `/etc/config/network`. Schnittstellen liegen dann mit einem VLAN-Suffix auf der Bridge, wie in `br-lan.1`. Jeder Port ist pro VLAN getaggt oder untagged.

## Auf Ihrem Router ansehen

```sh
ip -br link
uci show network | grep -E 'bridge-vlan|=device'
```

Sehen Sie stattdessen Abschnitte `config switch` und `switch_vlan`, verwendet das Gerät weiterhin swconfig, und DSA-Anleitungen gelten dafür nicht.
