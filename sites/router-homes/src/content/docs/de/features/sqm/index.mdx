## In einem Satz

SQM (Smart Queue Management) drosselt den Verkehr leicht unter Ihrer Leitungsrate, sodass sich die Warteschlange im Router bildet, wo sie verwaltet werden kann, statt im Modem. Zusammen mit der Queueing-Disziplin CAKE hält es die Latenz niedrig, während die Leitung ausgelastet ist. Dieses Problem heißt Bufferbloat.

## Was der OpenWrt-Leitfaden empfiehlt

1. Installieren Sie `luci-app-sqm`, oder `sqm-scripts`, wenn Sie LuCI nicht verwenden.
2. Messen Sie Ihre tatsächliche Download- und Upload-Geschwindigkeit und setzen Sie beide auf **90 %** des gemessenen Werts.
3. Wählen Sie `cake` mit `piece_of_cake.qos`.
4. Testen Sie erneut unter Last und passen Sie an. `fq_codel` mit `simple.qos` ist die leichtere, weniger vollständige Alternative.

CAKE ist seit 4.19 im Linux-Kernel.

## Auf Ihrem Router ansehen

Nach der Installation von SQM:

```sh
cat /etc/config/sqm
```

## Achtung

- Das Shaping beansprucht CPU. Auf einer schnellen Leitung kommt ein kleiner Router möglicherweise nicht mit; vergleichen Sie daher Geschwindigkeit und Latenz davor und danach.
- Legen Sie die Raten anhand einer Messung fest, nicht anhand der beworbenen Geschwindigkeit Ihres Tarifs.
