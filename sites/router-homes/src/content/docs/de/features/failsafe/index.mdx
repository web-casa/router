## In einem Satz

Der Failsafe-Modus startet OpenWrt mit einer minimalen, bekannten Konfiguration unter `192.168.1.1`, damit Sie eine defekte Einrichtung reparieren können. sysupgrade ersetzt die Firmware und behält Ihre Konfiguration, sofern Sie nichts anderes angeben.

## Failsafe-Modus

- **So gelangen Sie hinein:** Beim Booten gibt es ein Zeitfenster von 2–4 Sekunden. Drücken Sie dann fast eine beliebige Taste am Gerät oder an einer seriellen Konsole `f` und Enter.
- **Was Sie erhalten:** Der Router startet unter `192.168.1.1/24` mit ausgeschaltetem DHCP und WLAN und nur den wichtigsten Diensten. Geben Sie Ihrem Computer eine statische Adresse in diesem Subnetz und verbinden Sie sich dann per SSH.
- **Was Sie tun können:** Führen Sie `mount_root` aus, um das Overlay einzubinden und Dateien zu reparieren, oder setzen Sie mit `firstboot && reboot` alle Einstellungen zurück.
- Failsafe benötigt ein SquashFS-Image.

## sysupgrade

- Es behält die Konfiguration standardmäßig. `-n` flasht ohne sie zu behalten.
- `sysupgrade -b <file>` schreibt ein `.tar.gz`-Backup der in `sysupgrade.conf` aufgeführten Dateien. `-r <file>` stellt eines wieder her, und `-l` listet auf, was gesichert würde.

## Auf Ihrem Router ansehen

Dieser Befehl liest nur:

```sh
sysupgrade -l | head
```

## Achtung

- Ein Werksreset löscht alle Einstellungen, machen Sie daher zuerst ein Backup.
- Failsafe bietet kein DHCP. Ohne statische IP an Ihrem Computer sieht es aus, als wäre der Router tot.
