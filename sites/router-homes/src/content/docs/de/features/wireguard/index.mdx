## In einem Satz

WireGuard ist seit Linux 5.6, veröffentlicht am 2020-03-29, Teil des Mainline-Kernels. Unter OpenWrt ist es ein Netzwerkprotokoll namens `wireguard`, das Sie wie jede andere Schnittstelle einrichten.

## Die Bausteine

- `kmod-wireguard`: das Kernelmodul.
- `wireguard-tools`: der Befehl `wg`. Es hängt vom Kernelmodul ab und registriert das Protokoll `wireguard` bei netifd.
- `luci-proto-wireguard`: fügt „WireGuard VPN“ als Protokoll hinzu, wenn Sie in LuCI eine Schnittstelle anlegen.

## Wofür es zu Hause dient

- **Server:** Ihr Heimnetz von außen erreichen.
- **Client:** den Datenverkehr des Routers, ganz oder teilweise, über einen entfernten Peer senden.

In beiden Fällen ist der Tunnel eine Schnittstelle in `/etc/config/network`. Er braucht eine Firewall-Zone und auf einem Server einen offenen UDP-Port am WAN.

## Auf dem eigenen Router ansehen

```sh
wg show
uci show network | grep wireguard
```
