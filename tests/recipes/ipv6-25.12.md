# E2 recipe: IPv6 LAN ULA/RA/SLAAC on OpenWrt 25.12

## Status

E2 partial, run 2026-10-20. LAN ULA/RA/SLAAC and router reachability verified; no upstream GUA/PD.

## Environment

- PVE 9.2.2; OpenWrt 25.12.6 x86 VM 200; LAN `br-lan 192.168.1.2/24`.
- ULA prefix `fd2f:385b:7d0a::/48`; `ip6assign=60`; odhcpd running.
- Client: PVE netns veth; `accept_ra=2` for the lab.

## Steps

1. Baseline:
   ```sh
   ip -6 addr show br-lan
   ip -6 route
   uci show network.globals
   uci show network.lan
   uci show dhcp.lan
   ```
2. Confirm RA/DHCPv6:
   ```sh
   uci show dhcp.lan | grep -E 'ra|dhcpv6'
   ps | grep [o]dhcpd
   ```
3. Client:
   ```sh
   ip -6 addr show <iface>
   ip -6 route
   ping -6 -c 2 <router-ULA>
   ```
4. WAN IPv6 (not available here):
   ```sh
   uci show network.wan6
   ip -6 route
   ip -6 addr show eth1
   logread | grep -Ei 'odhcp6c|dhcpv6|pd'
   ```
5. DNS/firewall:
   ```sh
   nslookup -type=AAAA openwrt.org <router-ULA>
   uci show firewall
   ```

## Pass criteria

- LAN has ULA and sends RA.
- Client gets a /64 via SLAAC and can ping the router.
- No false claim of GUA/PD without an upstream.
- DNS/firewall checked separately.
